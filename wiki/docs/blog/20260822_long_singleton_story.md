# Мир до реальности

Вечер ушёл в синглтоны.

Чистили страховки: `if (not exists) extend`, `optional` на Core. Writing уже видит нормализованный мир, а тип орёт «проверь». Логика хозяина инварианта размазалась по всем Actions.

Потом полезли чинить фундамент наспех: Global в Reality сделать `optional`, кидать исключение, если не сетапнули. Омут. Пустой Wallet, Future держит ссылку на Global при любой транзакции, снаружи класса сыпятся `find_global` / `throw_unset`. Быстрый фикс калечит архитектуру.

Откат. Синглтон — просто `Id`, до `Interface::create` ядовитый ноль. Формально поле «чистое», по сути лживое. Жить можно. Честнее, чем optional в каждом caller.

Решение уровнем выше: **мир до Reality**. Куча мусора по схеме, без валидации. Метапроход «просетапься» приводит её в стартап. Потом уже Realm — и Writing больше не врёт.
