# Сегментация ностальгии

Вчера вспомнил историю, как мучался с UE 5.1 в 2023м, когда для внутренней тулы в Design Studio
надо было сделать просто selection / hover через stencil и для этого пришлось рендерить айдишники
нескольких тысяч деталек машины (кажется у меня был эталонный файл с Model S) во floating-point текстуру

Функцию "запихай инт в 14 бить 16-битного float, потому что еще два бита почему-то и отчего-то кто-то портит"
я помню до сих пор :)

Из ностальгии сделал сегментацию выбранных деталек точь-в-точь как тогда, только это заняло около плучаса:
старенький голый OpenGL оказался быстрее могучего UE примерно в десятки раз.

Тупо хряпсь и работает.
